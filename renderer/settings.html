General

Dictation

Press once to start dictating, again to stop and transcribe. On GNOME/KDE Wayland, apps may not be able to grab global keys — instead, bind a system keyboard shortcut to earheart --toggle.

Optional. While dictating, pauses and resumes the take without ending it — same as the overlay's pause key. On Wayland, bind a system shortcut to earheart --pause instead.

Where the text goes

    Advanced

    Performance

    Max dictation length — a dictation that reaches the cap stops and transcribes on its own; nothing is lost. Raising it lets the cleanup model hold more of what you say, at the cost of some memory; a dictation longer than it can hold is still transcribed and delivered, just as spoken.

    Unload models after idle — built-in models stay in memory for fast repeat dictations, then unload after this many idle minutes to free memory (~1.5 GB or more); 0 keeps them loaded for the whole session. The next dictation reloads them in a few seconds, usually hidden while you're still speaking. Only affects in-app models, not external services.

    Auto-paste permission

    Auto-paste types into the focused app, which macOS allows only with Accessibility permission. If pasting stopped working, click here to check the permission and open System Settings ▸ Privacy & Security ▸ Accessibility, then turn Earheart on (toggle it off and on again if it is already listed).
