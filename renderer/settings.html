General

Hotkeys

Press once to start dictating, again to stop and transcribe. On GNOME/KDE Wayland, apps may not be able to grab global keys — instead, bind a system keyboard shortcut to earheart --toggle.

Double-tap starts hands-free dictation with two quick presses; a single press while dictating stops it at once. A lone tap does nothing. The start is held back about 0.12 s to tell a tap from a held key. The tray and earheart --toggle always toggle. On Wayland, bind a system shortcut to earheart --tap instead.

Longest gap between the two taps, 250–1000. Raise it if double taps are missed.

Optional. While dictating, pauses and resumes the take without ending it — same as the overlay's pause key. On Wayland, bind a system shortcut to earheart --pause instead.

Optional. Throws away the dictation in progress — same as the overlay's ✕ key. Held only while dictating. On Wayland, bind a system shortcut to earheart --discard instead.

Open your last saved transcript, correct a spelling and remember it. Optional. On Wayland, bind earheart --correct-last in your desktop settings.

Open navigation, common actions and saved dictations. Leave empty to disable the global shortcut. Desktop bindings can run earheart --palette.

Microphone

Automatic picks the system default when it is allowed below, otherwise the first allowed microphone. If none is allowed it uses the system default and says so on the card.

This system doesn't report which microphones are Bluetooth or virtual, so these two options may not change anything here.

The input dictation records from when the choice above is the microphone below. System default follows whatever your OS has selected. Your pick stays saved while automatic is on.

Where the text goes

Pasting inserts the transcript at your cursor by briefly using the clipboard — plain paste puts your previous clipboard back afterwards.

Auto-paste permission

Auto-paste types into the focused app, which macOS allows only with two permissions: Accessibility and Automation (controlling System Events). If pasting stopped working — for example, a permission still listed as on but no longer valid — click here to check both, clear the stale entry, and open the System Settings pane for whichever is off, then allow Earheart.

Appearance

Light or dark for the overlay and every window. System follows your OS.

Language

The language of menus, settings and notifications. It does not change the language you dictate in.

Voice commands

A separate mode for writing or rewriting by voice: say what to do, then review the result before it is used. Select text first to rewrite it, or select nothing to write something new. Ordinary dictation is never treated as a command.

Optional. Also in the tray menu. On Wayland, bind earheart --command in your desktop settings.

Your selected text and what you say are sent to this service. It is never used for anything but voice commands: the Cleanup service is not a fallback. What you say is still transcribed by your Speech-to-text setting.

Replacing only happens when you press the button, and only if the same window and selection are still there. Otherwise the result is just copied.

Transcription engine

Built-in runs NVIDIA Parakeet privately, with nothing to install. OpenAI-compatible points at a local server, OpenAI, Groq, and the like.

Runs on this device — your audio never leaves it
Sends audio to the endpoint below

Paste a Hugging Face URL or owner/model of a sherpa-onnx transducer bundle (encoder, decoder, joiner + tokens.txt) or Whisper export (encoder, decoder + tokens.txt), such as csukuangfj/sherpa-onnx-whisper-turbo. Other encoder-decoder models, such as NeMo Canary, aren't supported. Files with a published Hugging Face LFS SHA-256 are verified on download. Browse Hugging Face opens your browser on the Parakeet TDT exports, the family the built-in models come from.

Cleanup

Always replace

Exact replacements for words the speech engine keeps mishearing, applied to every dictation even with cleanup off. Whole words only, any capitalization; code in backticks, paths and URLs are left alone. History keeps the original transcript.

Cleanup engine

Built-in runs a model on this computer, with nothing to install. OpenAI-compatible points at Ollama, LM Studio, OpenAI, and the like.

Runs on this device — your words never leave it
Sends the transcript to the endpoint below

Paste a Hugging Face GGUF model URL or owner/model. Earheart lists its versions and downloads the one you pick. Files with a published Hugging Face LFS SHA-256 are verified on download. Browse Hugging Face opens your browser on chat GGUF models up to 12B parameters; smaller ones clean up faster.

The app calls {base URL}/chat/completions.

Cleanup style

Presets pair editing instructions with matched sampling values. Custom sends only your system prompt, using the raw sampling values below — no preset instructions.

Closer to your words More polished

Temperature and top-p allow more varied wording as they rise; top-k and min-p are cutoffs that filter harder as they tighten. top-k and min-p apply to the built-in engine only — external services receive temperature and top-p.

How much randomness each word choice gets. 0 always picks the most likely word; higher values vary the wording more. Cleanup works best low (0–0.4).

Samples only from the most likely words whose combined probability reaches this value. 1 = off; lower values cut the long tail of unlikely words.

Keeps only the K most likely words at each step. Lower is stricter — 20–40 is typical; 0 turns it off.

Drops words less likely than this fraction of the most likely word's probability. Higher is stricter — 0.05 is a light filter; 0 turns it off.

Dictionary

Names, jargon and product terms that often get misheard. When the transcript comes close to one, cleanup corrects it to the exact spelling listed here. Keep the list short and specific — a handful of terms works better than hundreds.

Formatting by destination
Rules

Capitalization and punctuation, chosen by where the text goes — separate from how much the cleanup edits. A website rule matches that exact site (github.com, not its subdomains or look-alikes) and beats an application rule (macOS bundle id, e.g. com.apple.Terminal), which beats the default. Website names are read from Safari and Chromium-based browsers on macOS only; elsewhere, or if detection fails, the default is used. It applies when cleanup is on. Only the site name is read, never the page.

            Max dictation length — a dictation that reaches the cap stops
            and transcribes on its own; nothing is lost. Raising it lets the cleanup model
            hold more of what you say, at the cost of some memory; a dictation longer than
            it can hold is still transcribed and delivered, just as spoken. 10–3600 seconds;
            a value outside that is saved as the nearest limit, and a blank keeps the
            current one.
          
        
          
        
            Unload models after idle — built-in models stay in memory for
            fast repeat dictations, then unload after this many idle minutes to free memory
            (~1.5 GB or more); 0 keeps them loaded for the whole session. The next dictation
            reloads them in a few seconds, usually hidden while you're still speaking. Only
            affects in-app models, not external services. 0–240 minutes; a value outside
            that is saved as the nearest limit, and a blank means 0.
